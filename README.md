# 🌿 Agarwood & Incense E-Commerce Platform

### 1. Introduction
This is a comprehensive e-commerce solution developed for a local business specializing in Agarwood (Trầm hương) and Incense products. The system is designed to simplify the sales process for elderly customers while maintaining robust inventory management.

### 2. Architecture
The project follows **N-Layer Architecture** using **C# .NET**:
* **DomainModels:** Core entities.
* **DataLayers:** Repository Pattern & Entity Framework.
* **BusinessLayers:** Logic for order processing and Guest Checkout.
* **Admin App:** Management dashboard.

### 3. Key Features
* ✅ **Guest Checkout:** Phone-number based identification (No login required).
* ✅ **Order Tracking:** Lookup orders via phone number.
* ✅ **Inventory Management:** Admin dashboard for products and categories.
